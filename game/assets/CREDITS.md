# Credits

All assets below are original to this repository unless noted otherwise.

## Fonts (`assets/fonts/`)
- **Depths Sans**, **Depths Sans Bold**, **Depths Serif** (v2): original pixel-styled fonts drawn for Echoing Depths
  on a 15-units-per-em grid (glyph bitmaps in `assets/fonts/src/glyphs_sans.py` and `glyphs_serif.py`), traced to
  TrueType by `assets/fonts/src/make_fonts.py` (needs fontTools). Released by the project as CC0.

## Encounter art (`assets/encounter/`)
- Encounter illustrations and placeholder hero portraits: original, generated from the scripts in
  `assets/encounter/src/` using only the master palette.

## UI kit (`ui/`)
- Panels, buttons, icons and divider: original, generated by `ui/src/make_ui.py` (master palette).
