# refs (orphan branch: reference material only)
Stills, contact sheets and low-res clips from Sea of Stars, Super Auto Pets and Slay the Spire, used ONLY by
critic agents for blind A/B comparison (tools/blind_pair.py). Never merged into the game, never shipped.
Private; mirrored to GitHub only so cloud sessions (which can't reach YouTube) can fetch it with
tools/fetch_references.sh. Source videos are listed in tools/fetch_references.sh on gauntlet-build.
